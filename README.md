# SeasonArt

Локальное macOS-приложение для Никиты: сезонные эффекты поверх рабочего стола и окон.

Реализация локального MVP начата по сохранённому плану.

Пользователь подтвердил личную локальную разработку и использование. Продажи, сервер и лицензирование пользователей не планируются.

Рекомендуемая основа черновика – адаптация зафиксированного Snowhush с сохранением его лицензии и авторства. Основной первый сценарий – снег на настоящих окнах. Дождь, листья и сакура сохраняются из основы. Sparkle и сетевые обновления удаляются. План предусматривает отдельные bundle ID и настройки, локальные обои и установку одной копии в `~/Applications/SeasonArt.app`.

Спецификация и технический путь доступны для проверки. Задача подготовки плана не запускает сборку, установку или изменение Oasis/Speakey.
