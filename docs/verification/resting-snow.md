# Неподвижные фигуры на снегу

Релиз 0.1.1, сборка 2. Проверка 7 ноября 2026, MSK.

Стоящая фигура сохраняет высоту основания при накоплении свежего снега. Таяние опускает её на оставшийся слой, перемещение окна переносит вместе с опорой. Качение и броски продолжают учитывать высоту поверхности. Округлое тело Dock остаётся твёрдой нижней границей.

Причина покачивания – непосредственная привязка неподвижной фигуры к высоте столбика, которая меняется при падении и оседании хлопьев. Правило неподвижной опоры действует на земле, окнах и Dock, включая коррекцию контактов между шарами.
