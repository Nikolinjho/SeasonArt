# Метель

9 ноября 2026, MSK. Локальные изменения поверх master `7562add`, установленная версия остаётся 0.1.5/build 6. Отдельный релиз с метелью не публиковался.

В режиме снега доступен переключатель «Метель». По умолчанию он выключен. Значение хранится в ключе `blizzard`, сохраняется при перезапуске и передаётся новым экранам. Переключение будит рендер. В других режимах пункт скрыт и ветер метели не применяется.

`BlizzardWind` создаёт непрерывные порывы и местные завихрения. Сила плавно нарастает и затихает с постоянной времени 0,9 секунды. Добавленная скорость ограничена 92 pt/s по горизонтали и 18 pt/s по вертикали. Глубина и фаза хлопьев меняют отклик. Хлопья продолжают опускаться как минимум с четвертью исходной целевой скорости. Метель не увеличивает число частиц и не запускает выключенный снегопад.

- До подключения ветра тест настоящей симуляции падал: горизонтальная скорость 2,16 pt/s вместо значения выше 10,13 pt/s. После подключения профильный прогон дал 32 теста без ошибок.
- Полный `swift test --disable-sandbox`: 237 тестов, 0 ошибок, 1 пропуск нативной проверки порядка снежного слоя перед скрытым Dock.

- Столкновения снега с Dock при метели проверены при 30/60/120 fps. Новый экран получает сохранённое значение настройки.

## Увеличение иконок Dock

Пользователь отдельно сообщил, что увеличенная иконка выступает через снег. Пассивно прочитаны настройки Dock: увеличение включено, `tilesize=47`, `largesize=76`, ориентация снизу, автоскрытие выключено. Текущая опора SeasonArt описывает корпус Dock через `SLSGetDockRectWithReason` и не содержит отдельных иконок. Accessibility выдаёт прямоугольники `AXDockItem`, но увеличение наведением не проверялось. Точные границы увеличенной иконки пока не подтверждены.

Актуальная установка с метелью и цельным сугробом описана в [проверке поверхности снега Dock](dock-snow-surface.md). Настройки Dock и разрешения системы агентом не менялись.
