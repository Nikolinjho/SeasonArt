# Шапки по видимому контуру иконки

Актуальная поставка и открытая нативная приёмка описаны в [проверке непрерывности снега Dock](dock-snow-continuity.md). Результаты ниже относятся к предыдущей сборке.

9 ноября 2026, MSK. Текущая установленная сборка поверх master `7562add`, с метелью и незакоммиченными изменениями шапок. Версия остаётся 0.1.5/build 6, новый релиз не публиковался.

Пользователь отверг прежний вид: волна находилась выше иконки и не выглядела лежащим на ней снегом. Прежний GPU-тест подтверждал видимость волны, но не контакт со значком.

Теперь основание шапки следует верхнему непрозрачному контуру изображения приложения, который читается из его настоящей иконки. Из AX-рамки исключаются служебные поля. Небольшое перекрытие 0,8 pt убирает зазор. Толщина снега имеет мелкие неровности, а широкое изгибание всей полосы отсутствует. Поперечная полоса перед увеличенной иконкой скрывается в её пределах. При уменьшении положение шапки следует измеренному контуру без дополнительного запаздывания. Физическая масса снега и опоры игрушек не меняются.

При недоступной геометрии шапка не рисуется. Приближение по указателю удалено. В меню снега при отсутствии доступа виден пункт «Снег на иконках: разрешить доступ…». Только нажатие этого пункта предлагает открыть настройки «Универсального доступа». При старте приложения запросов разрешений нет. Системное разрешение агентом не выдавалось.

## Ограничения

### Живая диагностика после сообщения пользователя

Временная сборка измерила состояние внутри самого SeasonArt: `AXIsProcessTrusted() == false`, список иконок пуст, увеличение включено, рамка Dock `[384, 6, 960, 60]`. Поэтому контурные шапки в этом процессе не получают геометрию и не рисуются. Доступность Accessibility у терминального Swift-прогона не доказывает доступ у установленного приложения.

Локальный снимок: `docs/verification/artifacts/dock-live/in-app-sample.json`. Нужен системный доступ для SeasonArt через пункт меню «Снег на иконках: разрешить доступ…». Без него проверка реального прилегания не завершена. Удержание указателя до выдачи доступа не требуется.

Временная запись отключена, диагностический код удалён. Восстановлена прежняя сборка без диагностики из `build/backups/20261109-111705-MSK-8a6b8040/SeasonArt.app`, SHA-256 установленного бинарника снова `9b312eefcd943662a385ea4d5028b745c8967fc0cd43c34d1dec95f41aa1eaa6`, строгая подпись прошла. Изменений геометрии по предположению не вносилось. `build/SeasonArt.app` после диагностической сборки нужно пересобрать перед будущим выпуском.

Живое увеличение агентом не проверено, общий указатель и фокус не занимались. Прочитаны текущие AX-рамки обычного Dock и осмотрен рабочий стол без наведения. Перевод AX-рамки в квадрат рисунка использует поля 1 pt по горизонтали и 6 pt снизу. Эти поля ещё нужно сверить на живой увеличенной иконке, как и крайние значки. Включение системного разрешения остаётся действием пользователя. При отсутствии разрешения остаётся обычный сугроб на Dock.
