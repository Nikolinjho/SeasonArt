# SeasonArt 0.1.8

10 ноября 2026, MSK. Версия 0.1.8, build 9.

Нижний снег физически раздвигается наружу движущимися гранями Dock. Масса сохраняется, сжатие не возвращает снег в прежние места. Маски следуют за увеличением Dock и выступающими иконками. Малые порции снега распределяются плавнее, отдельные шапки на бейджах внутри Dock скрыты. Прозрачные окна XCTest исключены из опор и перекрытий.

## Ограничения

Живое наведение для этого релиза не выполнялось. Сто циклов расширения Dock проверены моделью. После раздвигания снег продолжает оседать и может возвращаться под неподвижный Dock. Подпись использует локальный сертификат Oasis Dev, нотариализация Apple не выполнялась.
