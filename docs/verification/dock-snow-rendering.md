# Снег на Dock

7 ноября 2026

## Размытая полоса

Крупные мягкие хлопья переднего плана не накапливают снег. Столкновение с телом Dock останавливало их падение, а обработка оседания пропускала их. Хлопья оставались подскакивать у полки и собирались в размытую полосу. Такое же зависание возникало у обычных хлопьев при отключённом накоплении.

При касании верхней грани Dock декоративная снежинка теперь завершает полёт. Обычный снег при включённом накоплении продолжает переходить в сугроб. Снег из порыва ветра сохраняет отдельную обработку.

## Разрешение и порядок окон

Полоса Dock использует физическое разрешение экрана и тот же масштаб сглаживания. На Retina с масштабом 2 ширина текстуры составляет 3456 пикселей вместо 1728.

Окно полосы находится на уровне `dockWindow + 1`. Прямой запрос к WindowServer подтверждает порядок перед системным Dock. Значения `z_index` из Cua не использовались как доказательство после расхождения с прямым запросом. Дополнительный подъём до уровня строки меню в итоговый код не входит.

## Проверки

Два теста жизненного цикла проверяют завершение падения при отключённом накоплении и исчезновение крупных мягких хлопьев после остановки снегопада. Проверка передних хлопьев допускает, что мелкий дальний снег с меньшей скоростью ещё продолжает падать.

Проверки окна охватывают масштаб Retina, порядок перед настоящим системным Dock и пропуск кликов. Логи и приватные снимки находятся в исключённых из Git каталогах `docs/verification/artifacts/dock-haze/` и `docs/verification/artifacts/dock-retina/`.

Итоговый запуск `swift test --disable-sandbox`: 194 теста, 0 ошибок. Проверки упаковки: 19, OK. Установленная сборка прошла проверку подписи и сравнение хешей, настройки сохранены. На нативном снимке после установки прежней размытой полосы над Dock не видно.
