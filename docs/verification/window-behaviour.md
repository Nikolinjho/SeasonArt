# Снег и нативные окна

## Результат

Граничные тесты SnowLayer проходят. На встроенном экране подтверждены накопление на двух из трёх перекрывающихся окон, обновление слоя при программном перемещении и изменении размера, удаление контура после сворачивания и закрытия и пропуск клика в окно под снегом. Полная матрица поведения ещё не подтверждена.

## Окружение

Проверка 6 ноября 2026 года, 12:56–13:04 MSK. Один Built-in Retina Display, 1728 × 1117 pt, масштаб 2.0. Запущен SeasonArt PID 19139 из локального бандла. Режим – Снег, интенсивность – Слабая. Поверх полноэкранных приложений включено. Accessibility и ScreenCapture для запускающего процесса доступны.

Созданы три временных AppKit NSWindow размером 640 × 412 pt, со сдвигом 300 pt по горизонтали и 180 pt по вертикали. Эти окна видны в текущем Space, включая полноэкранный. Окна пользователя не перемещались и не закрывались. Программный набор действий выполнялся временным `/tmp/seasonart-windows`, исходник сохранён в `artifacts/window-harness.swift`.

Для доказательных PNG временно включена настройка «Показывать на снимках экрана». Исходное значение – false по умолчанию. После проверок значение возвращено в false. Режим, интенсивность, полноэкранная настройка и автозапуск этим прогоном не менялись.

## Автоматические тесты

Добавлен `Tests/SeasonArtTests/SnowLayerTests.swift`:

- Координаты 99, 100, 139.9, 140 для слоя с началом x=100, четырьмя столбцами шириной 10. Ожидания: nil, 0, 3, nil.
- Поиск столбца после смещения снега и сужения опоры. Удалённые столбцы перестают принимать попадания.
- Сохранение площади осевшего снега с учётом части, прошедшей мимо открытого края. Высоты неотрицательны.

```text
swift test --filter SnowLayerTests
Executed 3 tests, with 0 failures

swift test
Executed 7 tests, with 0 failures
```

Обе команды завершились с exit 0. SwiftPM запускался вне внешнего sandbox, поскольку вложенный sandbox manifest выдаёт `sandbox_apply: Operation not permitted`. Тесты сразу прошли на импортированной реализации. Падение до исправления не заявляется. Производственные файлы движка в рамках этой проверки не менялись.

## Проверка курсора и перетаскивания

Второй временный набор (`artifacts/brush-harness.swift`) повторно создал три окна. Через 75 секунд сохранён `artifacts/brush-before.png`, затем CGEvent mouseMoved прошёл по видимой верхней кромке окна 1 от x=160 до x=460 при y=593. Сохранён `artifacts/brush-after.png`. Форма тонкого слоя немного различается, но по этим двум кадрам нельзя уверенно отделить смахивание от естественного изменения снега. Смахивание остаётся неподтверждённым.

Реальное перетаскивание отдельного временного окна подтверждено набором `artifacts/drag-harness.swift`. Последовательность CGEvent mouseDown, 30 mouseDragged и mouseUp отправлялась из фоновой очереди, которая продолжает работать во время обработки перетаскивания AppKit. До действия рамка окна была (150, 180, 640, 412), после – (295, 122, 640, 412), `moved=true`. Процесс завершился с exit 0, закрыл своё окно и восстановил курсор. Настройки приложения не менялись. Лог – `artifacts/drag-harness.log`.

Этот короткий прогон доказывает доставку настоящего drag сквозь overlay и перемещение нативного окна. Заметный сугроб на новом окне не ожидался, поэтому перенос накопленного снега во время drag остаётся отдельной визуальной проверкой.

Финальные настройки, прочитанные через `defaults read dev.nikoko.SeasonArt`: mode=0, snowfall=1, showOverFullScreen=1, showInScreenshots=0. Оба временных процесса завершились. Логи – `artifacts/window-harness.log` и `artifacts/brush-harness.log`.

## Ограничения

- Перенос заметного сугроба при реальном перетаскивании, изменение размера мышью и отчётливое смахивание снега курсором не подтверждены. Программное изменение рамки покрывает обновление положения опоры, отдельный короткий drag подтверждает движение окна под overlay.
- Переходы между обычным и полноэкранным Space, Mission Control и сон с пробуждением не проверялись. Текущая видимость снега в полноэкранном Space подтверждает только настройку «Поверх полноэкранных приложений» в текущем состоянии.
- Интерактивный выбор отдельного окна системным инструментом снимков экрана не проверен.
- Второй монитор и перенос Dock между экранами не проверены: физически доступен один экран.
- Сохранение массы и форма сугроба на всех трёх окнах требуют отдельного более долгого визуального прогона. Слабая интенсивность за 70 секунд не дала отчётливого слоя на втором окне.
- PNG показывают состояние через несколько секунд после действия, а не каждый кадр перехода. Нулевой кратковременный артефакт во время анимации ими не доказан.
