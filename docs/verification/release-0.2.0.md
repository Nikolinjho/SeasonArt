# SeasonArt 0.2.0

11 ноября 2026, MSK. Версия 0.2.0, build 10.

Физика снежков и снеговиков переведена на Box2D 3.1. Цикл физики работает с фиксированным шагом от частоты экрана. Снег у Dock сдвигается пологим валом, держит форму, открытый край оплывает пологим скатом. Снег на полке привязан к увеличенным иконкам. Маска нижнего снега повторяет скругление углов Dock.

## Ограничения

Автоматическая проверка живого наведения и перетаскивания не выполнялась. Горки у боков Dock после долгого снегопада полностью не устранены, их источник не исследован. Снег не скатывается в снежок при лепке. Снежок, отодвинутый Dock, не толкает сугроб. Подпись использует локальный сертификат Oasis Dev, нотариализация Apple не выполнялась.
