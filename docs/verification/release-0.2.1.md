# SeasonArt 0.2.1

11 ноября 2026, MSK. Версия 0.2.1, build 11.

## Поведение

Переключатель «Разноцветные светлячки» сохраняет выбор между запусками. Каждый огонёк имеет постоянный оттенок, смена палитры сохраняет координаты. Огоньки распределяются по всему экрану, соседи расходятся, неподвижный курсор слабо отклоняет ближайшие траектории после 0,6 секунды.

Урон всем трём шарам снеговика растёт с высотой свободного падения. Вершина броска вверх учитывается. Падение строго выше трети высоты текущего экрана разбивает фигуру на повреждённые снежки с разлётом и крошкой. Числовой допуск Box2D на пороге – 0,001 pt. При полном лимите 64 объектов части без свободного места превращаются в крошку. Рука, окно и парковка в другом Space не наносят урон. Посадка на промежуточную опору завершает текущее падение.
