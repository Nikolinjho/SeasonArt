# Отступ у строки меню для всех режимов

8 ноября 2026, MSK. Версия 0.1.4, build 5.

Настройка «Пропускать окна у строки меню» исключает опоры окон в пределах 38 pt под нижней границей строки меню во всех режимах. Снег, листья и лепестки пролетают дальше без накопления, дождь и метеоры не сталкиваются с исключёнными верхушками. Светлячки продолжают свободный полёт. Dock сохраняется в списке опор.

Значение настройки хранится в прежнем ключе skipSnowNearMenuBar. Переключатель доступен во всех режимах. При выключении возвращается полный список опор. Зимние игрушки продолжают получать исходные опоры независимо от фильтра частиц.

Причина прежнего поведения: ScreenSnow применял общий фильтр только при mode == .snow. Условие режима удалено, фильтрация вызывается через particleWindowUpdate. Переходы между режимами больше не меняют политику фильтрации, изменение самой настройки сбрасывает кэш трекера и будит рендер.

MenuBarEffectsTests использует настоящий ScreenSnow и проверяет все шесть режимов, границу зоны, Dock, отключение настройки и неизменность исходного обновления. До исправления тест дал пять несовпадений, по одному для каждого режима кроме снега. После исправления 11 профильных тестов прошли.

Логи: /tmp/seasonart-menu-bar-effects-red.log, green.log и full.log. Жесты общего указателя в этой проверке не используются.

Полный `swift test --disable-sandbox`: 227 тестов, 0 ошибок, 1 пропуск проверки порядка снежного слоя перед системным Dock, поскольку Dock скрыт. Остальные проверки Dock прошли.
