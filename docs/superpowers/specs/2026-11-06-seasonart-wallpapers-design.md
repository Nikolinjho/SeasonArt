# Сезонные обои SeasonArt

Продолжение согласованного направления приближения к KoiArt: сезонные комплекты с превью. Первый набор содержит одну собственную зимнюю иллюстрацию. Остальные сезоны добавляются отдельными материалами без пустых карточек.

Рассмотрены три пути: оставить только файловый диалог, открыть небольшую нативную галерею либо делать отдельный интерфейс настроек. Выбрана нативная галерея AppKit: она даёт превью и явное применение, сохраняя текущую архитектуру и локальный режим.

Пункт «Сезонные обои…» открывает окно с иллюстрацией «Зимнее озеро» и кнопкой «Применить на всех экранах». Существующий выбор своего файла остаётся доступен. Открытие, закрытие и выбор превью не меняют обои, эффект или его интенсивность. Применение выполняется только кнопкой.

Изображение входит в подписанный бандл. При применении оно атомарно сохраняется в Application Support/SeasonArt/Wallpapers с постоянным версионным именем. NSWorkspace получает URL этой копии, поэтому резервные бандлы и откат приложения не удаляют используемую картинку. Внутри приложения нет генерации, скачивания и сетевых зависимостей.

Ошибки чтения, сохранения и частичные ошибки экранов показываются через существующий русский NSAlert. Тесты проверяют корректность локального кэша, восстановление повреждённой копии, отсутствие изменений при отмене и неизменность исходного ресурса. Packaging проверяет наличие иллюстрации внутри подписанного бандла.

Критерии: нативное превью открывается из установленного приложения, закрытие сохраняет текущие обои, ресурс читается без сети, 27 исходных Swift-тестов и новые тесты проходят, подпись установленного бандла корректна. Пользовательские обои в рамках проверки не меняются.
