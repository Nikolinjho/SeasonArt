# Снег у строки меню

**Цель:** переключатель позволяет пропускать снег мимо верхушек окон в пределах 38 пунктов под строкой меню.

**Решение:** `WindowUpdate` фильтрует только опоры снежной симуляции. Исходный список продолжает поступать зимним игрушкам. Dock сохраняется в списке опор. Настройка включена по умолчанию и применяется только в режиме снега.

**Стек:** Swift, AppKit, XCTest.
