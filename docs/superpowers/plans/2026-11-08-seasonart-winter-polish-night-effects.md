# Доводка зимы и недостающие эффекты

Поручение: довести зиму по сохранённым роликам KoiArt, затем добавить недостающие элементы.

## Зима

- [x] Проверить конечную координату броска через настоящую цепочку view/model. Исправить потерю движения в mouseUp, сохранив спокойную установку после паузы.
- [x] Запретить запуск трактора, пока сцена скрыта системным выбором окна. Существующий проход должен продолжиться после возврата.
- [x] Добавить снеговику угольную улыбку с масштабированием по голове. Шары до сборки остаются без лица.
- [x] Прогнать зимние регрессии, осмотреть реальный AppKit-рендер.
- [ ] При разрешении на общий указатель выполнить живую лепку, перенос, сборку и уборку. Без разрешения оставить эту приёмку открытой.
- [ ] Исчезновение снега у Dock исправлять только после воспроизведения и установления причины.

## Следующий этап

Оба режима реализованы. Модель, интеграция с симуляцией, сохранение настроек и настоящий GPU-рендер включены в полный набор из 226 тестов. Живая проверка общего указателя остаётся открытой.

Светлячки: отдельный режим со светящимися частицами, плавным движением и притяжением к неподвижному указателю.

Звездопад: отдельный режим с редкими метеорами, светящимся следом и искрами при столкновении с открытой верхней границей окна или нижним краем экрана.

Сохранённые значения режимов 0–3 остаются прежними. Новые режимы добавляются в конец enum и меню. Интенсивность использует существующий контрол. Пауза, Spaces, энергосбережение и пропуск кликов работают через существующий renderer и ScreenSnow.

Проверки новых режимов: численная устойчивость на 30/60/120 fps, реакции на указатель и доступные опоры, отсутствие частиц после выключения, сохранение настройки, полный Swift-набор и packaging.
