# Ретроспектива 6 ноября 2026 года

Сигнал из диалога: снег был виден только при переключении Spaces. Фактический Space оказался полноэкранным Chrome, показ поверх fullscreen был выключен. Обычного списка окон оказалось недостаточно для определения Space. Проверка типа Space и настройки объяснила поведение без изменения движка.

Повторные проверки подписи внутри sandbox давали ошибку доверия, хотя те же команды вне sandbox проходили. Ограничение среды записано в README и журнале проверки.

Независимое ревью обнаружило два пропуска спецификации: защита от повторного запуска и диалог ошибки Metal. Они покрыты отдельными тестами и живым запуском.

Новые правила работы не предлагаются: существующие требования проверки причины ошибки и сверки со спецификацией уже покрывают эти случаи. Результаты сохранены как контекст проекта.

Продолжение: NSImageView растягивал новое окно до размеров исходной картинки. Проверка настоящего окна обнаружила это при успешных unit-тестах. Снижение приоритета сжатия подтвердилось повторным измерением bounds. Новый прогон курсора не засчитан: тестовое окно было закрыто другим приложением. Следующий нативный прогон требует проверки видимости своего окна до отправки событий.

Пользователь сообщил об отсутствии накопления на окнах. Причина находилась до симуляции: WindowTracker исключал развёрнутые окна и окна непосредственно под меню. Предыдущие интеграционные тесты начинались с готовых WindowSurface и не проверяли обнаружение таких окон. Новые тесты проходят через настоящий query со списком окон из контролируемых данных. Нативная проверка подтверждает оседание лепестков на видимом окне у строки меню.

Повторное сообщение об отсутствии оседания уточнило область: под Oasis. Предыдущее проверочное окно находилось преимущественно слева от прозрачного холста панели, поэтому его успешная проверка не охватывала перекрытие в центре. Диагностика настоящего WindowTracker показала ложную маску размером 960×360. Проверка нового исправления размещает верхний край окна целиком внутри этой области. Отдельные тесты различают прозрачную панель и обычное окно Oasis. Новое правило работы не требуется: этот случай покрывается существующим требованием воспроизводить конкретную геометрию ошибки.

Продолжение приёмки выявило ограничения проверочной программы: она считала всю рамку Dock препятствием и размещала тестовые окна под более высоким доступным краем развёрнутого окна. Глобальные события были пропущены защитой видимости, поэтому прогон не засчитан. Запрос fullscreen без подтверждения реального Space тоже не принят как доказательство. После обнаружения блокировки сеанса остановлена ожидающая программа UIProbe. Для продолжения нужен разблокированный сеанс и подтверждённая изоляция сцены до ожидания накопления. Это конкретизация существующих требований к воспроизведению, новое правило для агента не предлагается.
