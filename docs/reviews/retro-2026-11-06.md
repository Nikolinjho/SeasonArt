# Ретроспектива 6 ноября 2026 года

Сигнал из диалога: снег был виден только при переключении Spaces. Фактический Space оказался полноэкранным Chrome, показ поверх fullscreen был выключен. Обычного списка окон оказалось недостаточно для определения Space. Проверка типа Space и настройки объяснила поведение без изменения движка.

Повторные проверки подписи внутри sandbox давали ошибку доверия, хотя те же команды вне sandbox проходили. Ограничение среды записано в README и журнале проверки.

Независимое ревью обнаружило два пропуска спецификации: защита от повторного запуска и диалог ошибки Metal. Они покрыты отдельными тестами и живым запуском.

Новые правила работы не предлагаются: существующие требования проверки причины ошибки и сверки со спецификацией уже покрывают эти случаи. Результаты сохранены как контекст проекта.

Продолжение: NSImageView растягивал новое окно до размеров исходной картинки. Проверка настоящего окна обнаружила это при успешных unit-тестах. Снижение приоритета сжатия подтвердилось повторным измерением bounds. Новый прогон курсора не засчитан: тестовое окно было закрыто другим приложением. Следующий нативный прогон требует проверки видимости своего окна до отправки событий.
