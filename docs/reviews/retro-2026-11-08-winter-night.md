# Ретро: зима и ночные эффекты

8 ноября 2026, MSK.

## Наблюдения

- Полный Swift-прогон внутри sandbox не видит NSScreen. Повтор вне sandbox проходит. Ограничение уже описано в предыдущем контексте, первый полный прогон следовало сразу выполнить с доступом к графической сессии.
- Код Metal хранится строкой и компилируется во время выполнения. Обычный Swift-тест модели не обнаружил фрагмент свечения, ошибочно добавленный в функцию дождя. Настоящий GPU-тест обнаружил несовместимый тип возврата, затем проверил видимость и оттенок обоих режимов.
- Кадр метеора на границе появления содержит мало видимых пикселей. Для проверки рендера выбран момент внутри полёта, усиление свечения проверено чтением GPU-текстуры и осмотром изображения.
- Пользователь уже поручил добавление недостающих режимов. Повторный запрос общего разрешения на разработку был лишним. Запрос времени для управления общим указателем остаётся отдельным требованием из сохранённых ограничений прошлой сессии.

## Решения

GPU-проверка включена в общий Swift-набор. Новых инструкций или скилов не требуется. Живая проверка указателя не подменяется модельными тестами, баг исчезновения снега у Dock остаётся открытым до воспроизведения.
